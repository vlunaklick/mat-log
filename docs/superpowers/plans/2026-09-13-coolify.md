**Architecture:** Create a production Compose service on the existing VPS. Copy PostgreSQL data offline into the Coolify-managed volume and preserve the domain. Retain the original volume for rollback. Back up database and deployment configuration before stopping the legacy containers.

**Tech Stack:** Coolify, Docker Compose, nginx, Node, PostgreSQL 18.
